# Kanban Clone

Next.js Kanban pet project: create boards, manage issue cards in columns, drag-and-drop reordering with LexoRank, MongoDB storage, search and modals—showcasing clear board UX without aiming for full production completeness.

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Configure MongoDB via `.env` (see `.env.example`).
